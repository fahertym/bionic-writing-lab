# BWL ↔ ICN Boundary

**Session:** BWL Library Reconstruction, 2026-09-07
**Status:** boundary definition. No ICN work done, none authorised by this note.

The guardrails are inherited from the Villain closeout and are **binding**:
the books are not ICN propaganda; ICN need not be the subject of books about
something else; the political and philosophical arguments must survive even if
ICN fails; ICN is one experimental implementation, never proof by assertion.

---

## Four roles, kept separate

**1. ICN AS SUBJECT** — where a work actually explains ICN.
*Currently: nowhere in the book corpus, and that is correct.* If it ever
happens it is its own volume, written as documentation, not smuggled into a
political book as a resolution.

**2. ICN AS DESIGN LAB** — where implementation tests institutional hypotheses.
This is ICN's real relationship to the library. Claims about scoped authority,
revocable consent, anti-capture and subsidiarity are **testable** there in a
way prose cannot test them. When an invariant survives contact with a running
adversarial system, that is worth more than a paragraph asserting it should.

**3. ICN AS EVIDENCE** — where a working mechanism shows another arrangement is
possible. Legitimate, and strictly bounded: it demonstrates *possibility*, never
*superiority*, and never *inevitability*. One sentence, cited, then move on.
The moment a chapter's argument depends on ICN working, the chapter has failed.

**4. ICN AS BWL INFRASTRUCTURE** — author identity, canonical editions,
provenance, version history, archival authorship, rights, cooperative
publishing, distribution, preservation, reader-owned libraries, contributor
compensation, governance, federated storage.
`FUTURE_RESEARCH_HYPOTHESIS`. Genuinely interesting, because the Villain pass
produced exactly the kind of provenance record such a system would need to
carry. **Not a task for this year and not a dependency for any book.**

---

## The test that keeps this honest

Before ICN appears in any manuscript, one question:

> **If ICN did not exist, would this paragraph still be true and still land?**

If no, the paragraph is advertising. Cut it.

## The objection that must survive into the prose

From `constructive-corpus.md`, and it is the uncomfortable one:

> A system whose legitimacy rests on invariants only engineers can audit has
> relocated the priesthood rather than removed it.

The corpus makes exactly this critique of theology, of law, and of finance. It
would be dishonest to exempt our own preferred mechanism. **Any book that
mentions ICN constructively must also carry this objection**, or it fails the
same audit it applies to everything else.

That is not a concession. It is the seventh step of the method working
correctly.
